# Mohammad-Amin Aminian

**Geophysicist · Scientific-software developer**

I develop reproducible tools for **ocean-bottom seismology, seismic signal processing, seafloor compliance and inversion**.

My flagship project, [ComPy](https://github.com/MohammadAmin-Aminian/ComPy), brings together seafloor-compliance processing, pressure-gauge calibration and layered elastic inversion. It accompanies our [2025 paper in Geophysical Journal International](https://doi.org/10.1093/gji/ggaf253), *Shallow crustal structures of the Indian ocean derived from compliance function analysis*.

Selected software: [OBS Transient Cleaner](https://github.com/MohammadAmin-Aminian/obs-transient-cleaner) · [ComPy Inversion Tuner](https://github.com/MohammadAmin-Aminian/compy-inversion-tuner) · [RHUM-RUM Geospatial Mapper](https://github.com/MohammadAmin-Aminian/rhum-rum-geospatial-mapper) · [VRE Seismic Enhancement](https://github.com/MohammadAmin-Aminian/vre-seismic-enhancement) · [Gabor Seismic Filter](https://github.com/MohammadAmin-Aminian/gabor-seismic-filter)
